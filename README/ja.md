### 桐生トアの GitHub へようこそ！

僕は、日本を拠点に活動する学生・個人開発者です。

TypeScriptを中心としたWebアプリケーション、開発者向けツール、ライブラリ、APIなどの設計・開発を行っています。

フロントエンドからバックエンド、インフラまで幅広い領域に取り組み、個人開発やオープンソースソフトウェアの開発を中心に活動しています。

技術の探究と実用性を重視し、自由で持続可能なソフトウェア開発を目指しています。
